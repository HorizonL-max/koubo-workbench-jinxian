# 第 5 部分　全片逐镜（P12–P64，三幕）

> 写法和第 2 部分一样。`S9「好的大学」f1838` = timestamps.json 第 9 句里「好的大学」第一个字的起点帧（脚本算的，= `WF('好的大学', 近似秒)`）；做的时候照旧用词锚函数现查，别抄秒数。没带词锚的帧号是相对镜头入点排的。
> 画面上的字全部是口播原话的连续片段（脚本逐条核过）；例外只有顶牌（本期标题）和字幕英文行。
> 每镜的「音效」一行格式固定：`#序号 帧 采样名 音量（动作）`，每幕末尾有汇总表，同一份数据另存在 `sfx_plan.json`。

**每幕单独开工、互不改对方文件**（建议的文件分法，第一幕的制作先搭好空壳，后两幕只往自己的文件里写）：
- 镜头表 / 人物形态表：`src/shots.ts` 换成全片 64 镜（从 `shots.json` 抄）；`Host.tsx` 的 `ROWS` 按幕拆成 `rows.act1.ts / rows.act2.ts / rows.act3.ts` 再合并。
- 字幕：`CUES` 拆成 `cues.act1.ts / act2 / act3`（下面每幕的字幕分条表照抄），`Subtitles` 合并读。
- 音效：`sfx.act1.ts / act2 / act3`，`sfx.ts` 合并。
- 场景：`src/scenes/act2/…`、`src/scenes/act3/…`，在 `Main.tsx` 里各挂一个 `<Act2 />`、`<Act3 />`；第一幕接着用现在的 `src/scenes/`。

### 新采样（Freesound，CC0 优先；下载后量峰值位置，动作对峰值）

| 采样名 | 要找的声音 | 搜索词（两个词以内，样段踩过坑） |
|---|---|---|
| paper | 一张纸片在桌面上滑一下 / 放下 | `paper slide` |
| pencil | 铅笔在纸上画一小段 | `pencil sketch` |
| spin | 硬币在桌面上旋一下 | `coin spin` |
| rope | 细绳 / 麻绳被拉紧的一声吱 | `rope creak`、`rope tighten` |
| stamp | 木头印章盖在纸上 | `rubber stamp`、`stamp paper` |
| step | 石板路上的一步（硬底鞋，单步） | `footstep stone` |
| book | 一本书轻轻放到桌上 | `book drop`、`book thud` |
| switch | 老式开关 / 舞台灯「咔哒」一声 | `light switch`、`spotlight switch` |
| door | 木推拉门滑开 | `sliding door` |
| page | 硬皮相册 / 厚书翻开，书脊轻响 | `book open`、`page turn` |
| card | 一张扑克牌甩出去落在桌上 | `card flick`、`playing card` |
| wood | 木头轻叩一下 | `wood knock` |
| drop | 一滴水落进水面 | `water drop` |
| snip | 剪刀剪断一根线 | `scissors snip` |
| creak | 木头受力吱呀一小声 | `wood creak` |

样段已有的 9 条（chime / brush / keys / clink / flip / tick / cloth / bell / lyre）照旧用。lyre 全片用得最多（线亮起、光点到达），连用时不升调、音量逐次略降。找不到合适真实录音的那条空着。
