# 第 1 部分　全片视觉系统「金线讲堂」

## 1.1 一句话和风格档（G0）

**一句话**：书房里的心理学讲堂——宋体字、香槟金细线、米白纸卡、夜青和檀棕两种暗场；全片有一条贯穿的图形线索：**金线**。那些「应该」是挂在金线上的相片吊坠，线从画面上方垂下来；片子越往后，观众越看清线的另一头是谁。

- 领域 / 口吻：心理 · 人生观点，对成年观众讲道理，语气平和、层层递进，不吓人、不喊口号。
- 从样片学什么：香槟金 + 米色纸面 + 深蓝绿 / 深棕暗场；粗宋体；卡片一格一格「写」出来；几乎全是硬切，动作都在元素内部；中文字幕下面一行小英文；右上（本片改左上）常驻标题牌；图文卡时人物缩成圆窗。
- 比样片多什么（用户原话「尽可能给我更多的画面动效」）：样片 65% 时间是静止口播，本片每个口播镜都有一件东西在长、在落、在翻；两个机位按句切换；全片一条金线母题把各段图解连起来。调性仍然克制：不抖屏、不闪白、不故障、不群发扫光。
- 能量：中低。全片最重的动作是「吊坠落位的小摆」和「徽章翻面」，没有砸、撞、震。
- 样板镜：P02（有人物、升格问句、金线、双语字幕、顶牌，全片共性都在）。**制作先做 P01+P02 出一条有声预览自查，再铺其余镜**。

## 1.5 常驻元素

### C01 顶牌（全片在，夜青图解镜让位）
- 位置 x 64–424，y 168–270。左缘一根竖金条 6×94（x 64–70，y 172–266）；托板 #140d07 α0.72、圆角 10、边缘羽化 6px（要够实，垂线从它后面过）。

- 让位：夜青图解镜里顶部要放别的标注时，顶牌 6 帧淡到 0，下一镜切回来时直接在。

### C02 金线字幕带（全片在）
- 中文一行：居中 x=540，行框 y 1271–1335，Songti Bold 58，**一条最多 13 个字**（14–15 字降到 54，再长就拆条）。英文一行：居中，y 1348–1390，Georgia 34，≤44 个字符。
- 字幕托：x 130–950，y 1250–1400，#140d07 α0.46，圆角 18，高斯羽化 14px，左右两端 90px 渐隐到 0；上下各一根金发丝线（y 1250、y 1400，x 190–890，1.5px，gold α0.6，两端渐隐）。
- 纸面幕底上换「纸面模式」：托板不要（α0），金线留着；中文墨色 #3a2a1c、强调字深金、英文淡墨，不加影。
- 素排：整条硬现硬走，不淡入、不逐字、不弹。不带标点。强调词只换颜色（亮金 / 深金），一条最多一个词。
- 拆条按气口，每条一口气；入点 = 该条第一个字起点 −2 帧，出点 = 下一条入点或本条末字结束 +0.25s（取早的）。字幕可以跨镜不断。
- **升格**（全片 ≤6 次，定稿 4 次：P02、P09、P45、P63）：这一条中文不在字幕带里出，改成大字 / 纸条出在字幕带上方，英文留在字幕带里；升格期间字幕带上面那根金线隐去，托板保留。
- 必须量：人物镜里字幕文字背后的平均亮度 Y ≤ 95/255（白 T 恤上尤其要量），不够就把托板 α 加到 0.55。

### 压暗层（人物镜、实拍镜都有）
- 顶部：#140d07 α0.50（y=0）→ 0（y=420）。
- 底部：#140d07 0（y=1400）→ 0.80（y=1700）→ 0.86（y=1920）。
- 压暗只在顶和底，**任何时候不盖到脸**（包括光斑、颗粒、金尘、漏光）。

## 1.7 两个机位和人物形态

**怎么分工**
- 中景（`host_ms`）正对镜头：对观众说话的句子——设问、「你看」「比如」、带吊坠 / 两侧字的镜头。**前 3.70s（0–110 帧）是黑的，不能用。**
- 近景（`host_cu`）眼睛看画面右侧，像在想事情：铺垫、转折前缓一口气、自问、金句前。脸很大（y 440–1235），除了顶区一行字和字幕带放不下别的东西，所以近景镜叠层最少，一次 ≤6s。
- 切点放在句首前 1–3 帧；同一句中间不切（切在逗号气口且内容需要时例外）；两次机位切换间隔 ≥2s。中景 → 近景是「收」，近景 → 中景是「放」。
- 调色：中景脸比近景亮约 15%、偏粉。中景镜统一加 `brightness(.94) contrast(1.03) saturate(.97)` 起步，制作阶段各抽 3 帧量脸部亮度，调到两机位差 ≤6%。

**七种形态**（shots.json 的 `host` 字段用这些名字；第七种 `AVATAR` 是用户看完样段后加的）

| 名 | 做法 | 能放东西的地方 |
|---|---|---|
| `FULL_CU` 近景满幅 | host_cu，scale 1.00↔1.03，原点 (52%,46%) | 顶区一行字；字幕带 |
| `FULL_MS` 中景原幅 | host_ms，scale 1.00→1.02，原点 (545,790)（头心，推的时候头不跑位） | 顶区、人两侧列、三枚吊坠 |
| `FULL_MSB` 中景上提 | host_ms，scale 1.15→1.17，原点 (50%,100%)；脸上移到 y 449–926 | 胸前区 y 940–1235 |
| `ROUND` 圆窗 | 直径 248，圆心 (540,1070)；取中景，脸居中（源画布 (545,800) 周围 520×520 缩进来）；金环 5px + 内侧 1px 乳白线 + 柔影；位置锁死不漂 | 上方 y 290–900 整块给卡片 |
| `ARCH` 拱窗 | 宽 580 × 高 660，x 250–830，y 300–960，顶部半圆；纸面幕底；取近景 | 下方 y 990–1235 一排纸签（样段没用） |
| `AVATAR` 小头像 | **凡是整屏实拍空镜都用它**（用户原话：「后面出全屏的 broll 的时候，可以让人物缩小成一个小头像在旁边讲」）。直径 176 的圆窗，圆心 (160,1128)，取近景，人不退场、口型同步。完整规格见 1.13 的 C21 | 头像占 x 60–260、y 1028–1228；这一镜里其他字和框的下沿不过 y 1000，或者整体在 x 280 右边 |
| `HIDE` 退场 | 人物不在画面。**只给代码画的图解（夜青 / 檀棕）和章节卡用，实拍镜不再退场** | 全屏。单次 ≤10s，全片 ≤30%（定稿 24%），开场 3 秒和最后一镜不退 |

## 1.8 组件库

每个组件写：用途 / 规格 / 动效 / 上限。★ = 样段里用到。

**★ C03 金粉扫字（片头标题）**　一团金色粒子从左往右扫，字跟着显出来；站稳后整块连续缩小落成顶牌。粒子 140 粒，固定种子，寿命 14–26 帧，向后飘 + 轻微下坠，r 1.5–5，色 #ffe9bf / #e9c58a / #c9a063，screen 叠加，约 12% 带四角星芒；扫头一团径向光 r 70。全片 1 次（片尾金句可以回扣 1 次）。动效照 shotcraft `title-demote-to-label`：站稳 ≥18 帧，降格 26 帧单次连续补间 `bezier(.6,0,.18,1)`，缩放和位移同一条曲线。

**★ C04 升格问句**　全片的几个大问句。中景上提；底部压暗上提（α0 @y940 → 0.80 @y1070 → 0.88 @y1400 以下）；两行大字居中，**字随声出**（每个字在自己的口播起点那一帧出现，8 帧 blur-slide：上移 0.3em、模糊 14→0、透明度同一条 ease-out）；重点词亮金，下面一道金线下划线。照 `blur-slide`（三通道共用一个进度）和 `marker-underline-title`（10 帧画完、中段宽约 0.12em、首尾细、边缘毛糙、宋体是正体所以水平微抖不上斜）。全片 ≤4 次。

**★ C05 金线吊坠（全片母题）**　一枚「应该」= 一枚挂在金线上的圆相片。
- 圆相片（徽章）：直径 208（头顶那枚 184）；外圈金环 5px（#f1d9a8→#c9a063→#8f6a34 渐变），内侧 7px 处一圈 1px 乳白线；里面是空镜，cover 铺满、统一调色；顶上一个小金扣 14×18；柔影 `0 10px 24px rgba(20,13,7,.35)`。左上一道静态高光弧 α0.18（不扫光）。
- 线：2px，gold α0.85，外发光 `0 0 4px rgba(233,190,120,.5)`，从画面顶边（y=0）垂到金扣。线从顶牌后面过。
- 吊牌：纸卡 #f4ecda，圆角 10，1px 深金边 α0.5，用 14px 短线挂在徽章下面；两行：小字 Songti Bold 32 深金（「一定要」「就应该」）+ 主词 Songti Black 44 墨色；宽 = 字宽 + 36，高 104（单行 72）。
- 落位：线先垂下来（12 帧 outCubic）；徽章从 y=300 处出现（透明度 0→1、scale 0.6→1），顺着线滑到位（14 帧，过冲 14px 回落）；然后整枚绕顶端锚点摆：θ = 2.6°·e^(−1.8t)·cos(2π·0.9t)。吊牌晚 6 帧从上往下展开（scaleY 0→1，8 帧，轻微回弹）。
- 常驻微摆：θ = 0.35°·sin(2π·0.18t + φ)，三枚相位各不相同。吊坠在场的镜头靠它和人物视频过静止检查。
- 三个落点（中景原幅）：左 (190,628)、右 (890,628)、头顶 (540,372)。头顶那枚的吊牌挂在右边（x 660–900，y 318–426）。
- 后面段落怎么回扣：第二章「父母的期待 / 学校的评价 / 社会的标准」再挂三枚；「把外部的标准当成自己内心真正的想法」一枚吊坠沉进剪影胸口；尾章「重新去决定未来的方向」人影自己伸手挂上一枚。每次回扣 ≥45s 间隔，一次在场 ≤12s。

**★ C06 徽章翻面**　吊坠的圆相片绕竖轴翻 180°，正反两面语义成对（结了婚 → 生个孩子；选择 → 问号）。照 `card-flip-reveal`：4 帧反向预备（−10°）→ 16 帧 `bezier(.55,0,.3,1)` 翻到 194° → 弹簧（damping 15）回落 180°；翻的时候面按 `1−|cosθ|` 压暗（≤0.55），侧棱在 56°–124° 之间有一道窄受光带、90° 最亮（这是物理受光，不算扫光）；perspective 1600。多枚错峰 5 帧，≤3 枚。翻完真静止只留微摆。

**★ C07 实拍出血 + 玻璃字框**　空镜铺满（`broll` 幕底）。字放在玻璃描边框里：圆角 26，乳白描边 3px α0.9，框内 backdrop-blur 8px + #140d07 α0.18；框的描边用 `draw-svg-trace` 画出来（带笔头，≥24 帧；描边圆角和框一致）；框画完字才出。实拍镜一次 ≤6s。

## 1.9 动效语言

- 出现：blur-slide（上移 0.3–0.38em + 模糊 14→0 + 透明度，同一条 ease-out，8–12 帧）；逐词错峰 4 帧，或直接按口播字起点「字随声出」。
- 画线：stroke-dashoffset，inOutCubic，带一颗亮笔头；线到哪亮到哪。
- 打字：逐字硬现，前面一根金色光标；只用在纸卡上。
- 挂件：带阻尼的摆，不用弹簧缩放。
- 入场永远比出场用力；出场 6–8 帧淡出或跟着切走。

- 不做：震屏、闪白、故障、负片、群发扫光、逐拍缩放、手持抖动、盖在脸上的任何叠层。
