# 风格H 金线讲堂 · 竖屏口播包装

风格本体在工作台的 `_kit/风格H/`：可复用的 Remotion 工程（`src/parts/` 二十多个组件、`src/ep/` 每期配置、`venue.ts` 读场地预设）、`tools/` 脚本、`场地预设.json`、`样片参考/`，以及说明书 `_kit/风格H/README.md`（视觉 token、组件目录、人物形态、双语字幕规则、配乐音效、每期必核、开工步骤、踩坑清单、成本基线）。

本技能管**这一套风格怎么用**；口播管线（字级时间戳、SHOTBOOK、字幕、机器闸）用 video-talkcraft，镜头语言和音效选材用 video-shotcraft，两个都要加载。工作台总约定在 `AGENTS.md`。

## 0. 先确认环境
```bash
bash setup/check_env.sh        # 有 [缺] 就按 koubo-setup 技能装
bash setup/smoke_test.sh       # 可选：8 秒样片 + 关键帧拼图（假人物），让用户先看风格
bash setup/selftest.sh         # 可选：一键自检，只打印通过 / 失败汇总表
```

## 1. 判断题材合不合适
适合：心理学、人生观点、成长、关系、知识讲堂，知性、温暖、克制的语气。
不太适合：冲击感强的吐槽 / 翻车、数码参数对比、价格快讯。题材明显不合适时告诉用户理由，由用户决定是否照用。

## 2. 开新一期
```bash
bash setup/new_episode.sh <账号>-<拍摄日期>-<主题>
```
然后**通读 `_kit/风格H/README.md`**，按「新一期怎么开工」走：双机位粗剪（`_tools/dualcam/`）→ 字级时间 + 声纹 → 按「每期必核」核 `场地预设.json` → 分镜（`tools/sb_build.py` 出 SHOTBOOK、`shots.json`、cues）+ `variety_lint` → 改 `remotion/src/ep/`（★ 项全改，Demo 场景整份换掉）→ preflight → 渲染 → postcheck → loudnorm。

## 3. 硬规
- **零件复用、分镜每期重做**：`src/parts/` 组件、`theme`、`Host`、`Subtitles`、音效、`tools/` 直接用；SHOTBOOK、版式、文案、场景代码每期重写，`样片参考/` 只看写法，不整份拷。每期至少 3～5 种新包装形式，新组件补进 `_kit/风格H/` 和 README 组件目录。
- **结构件每期复用、换文案即可**（不算进新形式）：C11 引语纸条 `QuoteSlip`、C15 概念牌 `ConceptPlaque`、C16 章节卡 `ChapterCard`、C17 金框牌 / C29 小金框 `FramePlaque`（给 `f,f0` 走描框）、C18 两答纸条 `TwoAnswers`（左右 / 上下 / 斜对三种摆法）、C20 金句卡 `QuoteCard`（在 `GlassFrame.tsx`）。参数和上限看 README 组件目录；改了这几个件后渲合成 `StructParts` 出拼图看一眼。
- **卡片文字只用口播原话**；剪辑和字幕以实际口播为准，保留临场发挥。
- **竖屏安全区**：底部约 20% 和右侧按钮列不放字幕和关键信息。
- **整屏实拍空镜时人物不退场**，缩成左侧金边小头像继续讲（口型同步，用近景机位）；图解卡、章节卡上人退不退按信息密度定。
- **双语字幕**：每句中文下一行小英文；画面字和字幕整句重复时隐藏那句中文字幕；升格句改成大字出在字幕带上方。
- **音效少而准**：真实拟音，重点音效放进句间停顿，被人声完全盖住的删掉；配乐是温暖钢琴 / 氛围，别用悬疑感的。
- **换场地 / 机位 / 座位**：先按 README「每期必核」重量 `场地预设.json` 里带 ★ 的项（人脸位置、头顶高度、小头像取景、遮挡区），不要直接套样片的数。
- **长片分段做**：3 分钟以上按幕拆分镜和制作，每段从干净上下文开始（工具支持子代理就用子代理），能显著省 token。
- **三道机器闸**：`tools/variety_lint.py`（分镜后）、`tools/preflight.py`（渲染前）、`tools/postcheck.py`（交付前），FAIL 不往下走。
- 踩到新坑：能自动查的加进 `_kit/风格H/tools/` 的脚本，查不了的补进 README「踩坑清单」。

## 4. 只有一台机位
见 README「只有一台机位时」：`files.ms` 指向同一个文件，只用近景形态，景别变化靠推镜。
